# AppVisual

アプリ紹介用スクリーンショットを制作するmacOS向けElectronアプリです。

```sh
npm ci
npm start
npm test
npm run build
npm run build:web
```

- 48種類のテンプレート（検索・レイアウト概略プレビュー）、追加装飾20種、背景パレット12種。
- デバイスを選び、右パネルでPNG/JPEG/WebP画像を読み込みます（12MBまで）。
- 保存した `.fcs` は画像も含み、別の起動時にも開けます。
- 作業は端末内のIndexedDBに自動保存します。画像を含む全ページに対応しています。大切な作品は「保存」でファイルにも残してください。
- 元に戻す／やり直すは最大35状態（大きな作品は履歴のメモリ容量に応じて短縮）。⌘/Ctrl+Z、Shift+⌘/Ctrl+Z、⌘/Ctrl+Dで複製、矢印キーで移動（Shiftで10px）、Deleteで削除。
- PNG書き出しはキャンバスの原寸です。パノラマは2枚に分割します。
- 写真素材とGoogle Fontsはインターネット接続が必要です。アイコン・画像書き出しライブラリ・背景パレットは同梱しています。

## 配布用ビルド

`npm run build:web` はGitHub Pagesなどにそのまま配置できる静的Webアプリを `public/` に生成します。`npm run build` はmacOS向けDMG/ZIPの任意ビルドです。

この版はAI機能を含まず、画像制作・保存・書き出しはすべて端末上で完結します。ネットワーク上のAPIやAWS認証情報は不要です。

## 公開前に必要な作業

製品用アイコン、配布者情報、Apple Developer ID による署名・公証、配布先でのインストール検証は別途必要です。実際のストア提出サイズと素材・フォントの利用条件は公開先に合わせて確認してください。Apple の Notarization 用認証情報はリポジトリやアプリ本体に保存しないでください。

未接続で故障していた動画・一括サイズ書き出しの内部実装は取り除き、現在の提供機能を画像制作に統一しています。自動テストは隔離したユーザーデータで48テンプレート、履歴、復元、不正データ拒否、画像描画を確認します。

## 自分の素材・背景を使う

- 「素材」→「画像素材をインポート」でPNG・JPEG・WebPを複数選択できます（1枚12MB、一度に30枚）。同じ欄へのドラッグ＆ドロップにも対応しています。
- 「マイ素材」は端末内のデータベースに保存され、アプリを閉じても再利用できます。「配置」で画像要素に、「背景」で背景に適用します。名前で検索できます。
- 「デザイン」→「背景画像をインポート」でも背景を読み込めます。「画面いっぱい」「画像全体を表示」を切り替えられます。
- 配置した画像は透過を保ち、縦横比を維持してサイズ変更できます。回転・不透明度、複製・レイヤー操作も利用できます。
- ライブラリから削除しても、配置済みの画像には影響しません。作品の `.fcs` 保存には使用した画像と背景が埋め込まれます。
- 図形12種類（円・角丸・星・リング）とパターン背景12種類（ドット・ストライプ・波紋）を追加しています。すべてローカル生成でオフライン利用できます。

## ページ管理・制作ワークフロー

- 1作品に最大20ページ。画面下で新規追加・複製・名前変更・並べ替え・削除ができます。ページ操作も元に戻せます。
- 「全ページを一括書き出し」でページ順のPNGをZIPにまとめます。1枚だけの場合はPNG、パノラマは左右2枚です。原寸と確認用0.5倍を選べます。
- 書き出し中は進捗とキャンセル操作が表示されます。描画用の複製を使うため、編集キャンバスの位置やページは変わりません。
- 保存先はmacOS標準ダイアログで選択します。プロジェクトは200MBまで。ファイルは一時ファイルへの書き込み後に置き換えます。
- 自動保存をIndexedDBへ移行しました。画像を含む全ページを端末内に保存し、アプリ終了前に保存完了を待ちます。以前の単一ページ `.fcs` と旧自動保存も読み込めます。
- 整列ガイドでキャンバスや他の要素の端・中央へ吸着します。Altで一時解除できます。左右・上下の整列ボタンもあります。
- レイヤーには名前を付けられ、固定・非表示・表示を切り替えられます。固定した要素は移動・削除・編集の対象から外れます。
- ブランド設定で名前、2色の背景、文字色、フォント、ロゴを登録できます。端末にプリセットを保存し、現在のページまたは全ページに適用できます。背景はブランド色に置換し、ロックされていないテキストに適用します。
- 画像素材は比率・位置・拡大率でトリミングできます。プレビューを確認して「適用」を押します。元画像を保持するためリセット可能です。画像の差し替えにも対応しています。
- マイ素材はお気に入りで絞り込めます。「使い方」から操作の流れを確認できます。

テストにはページ操作・ページをまたぐ履歴・トリミングの画素・元画像の復元・ブランド一括適用・整列・パノラマ分割・ZIPの内容・キャンセル時の後処理・旧形式移行・ネイティブ保存と終了前保存の確認を含みます。
